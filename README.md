## 最优策略说明

**MA20最优策略** (`ma20_optimal.json`) 是综合表现最好的策略：

- **交易规则**：收盘站上MA20买入，收盘跌破MA20卖出
- **过滤条件**：
  1. 成交量 > 20日均量 × 1.2（确认真突破）
  2. ATR > 20日ATR均值（过滤低波动震荡期）
  3. 价格偏离MA20 > 1%（避免假突破）
- **风控**：固定止损 5%

## 策略配置格式

```json
{
  "name": "策略名称",
  "description": "策略描述",
  "entry_rules": [...],    // 入场规则
  "exit_rules": [...],     // 出场规则
  "risk_management": {...}, // 风控参数
  "filters": {...},        // 过滤条件
  "backtest_result": {...} // 回测结果
}
```
